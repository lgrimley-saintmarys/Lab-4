# Problem 1
Design the function flatten that takes a (possibly deep) np.array and "flattens" it.  That is, removes any internal nesting so that it is just a single, one dimensional array.

# Problem 2
Consider the class of one dimensional np.arrays which are sorted in ascending order (duplicates are allowed).  Design the function merge which takes in two sorted arrays and returns a new array that contains all of the elements in the two arrays in sorted order.

# Problem 3
Create a string which consists of 400 randomly generated integer values between 0 and 10 with commas separating the numbers.  Write a function which takes in a string of comma-separated values and creates a 2 dimensional array with 4 entries per line.

# Problem 4
Design a function chessboard which takes in a number, n, and produces a two dimensional nxn array with an alternating pattern of 0's and 1's across the row and columns starting with a 1 in (0,0) position.

# Problem 5
Design a function nearest that takes in an array and a number and returns the value closest to that number in the array.
